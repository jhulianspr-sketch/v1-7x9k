# Carpeta de Imágenes - Parche Digital

## Propósito
Esta carpeta está diseñada para almacenar todas las imágenes de portadas y recursos visuales del blog "Parche Digital".

## Estructura Sugerida
```
images/
  posts/              # Imágenes de portadas para los posts
    motivacion/
    consejos/
    vida-diaria/
    metas/
  banners/            # Imágenes para banners y headers
  logos/              # Logotipos y branding
  social/             # Imágenes para redes sociales
  backgrounds/        # Imágenes de fondo
```

## Formatos Recomendados
- **Portadas**: JPEG/PNG, 1200x600px (16:9)
- **Thumbnails**: JPEG/PNG, 400x250px (16:10)
- **Banners**: JPEG/PNG, 1920x1080px (16:9)
- **Redes Sociales**: JPEG/PNG, 1080x1080px (1:1)

## Convención de Nombres
- Usar nombres descriptivos y en minúsculas
- Separar palabras con guiones (-)
- Incluir fecha si es relevante: `post-motivacion-2024-04.jpg`

## Optimización
- Comprimir imágenes para web (máximo 200KB por imagen)
- Usar formato WebP para mejor rendimiento
- Mantener relación de aspecto consistente

## Créditos
- Actualmente usando Picsum Photos para imágenes placeholder
- Reemplazar con imágenes propias o con licencia apropiada
