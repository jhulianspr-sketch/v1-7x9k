# 🚀 Parche Digital - Blog Cyberpunk

> **Blog moderno para jóvenes con contenido motivacional, consejos y vida diaria**

## 📋 Descripción del Proyecto

**Parche Digital** es un blog moderno con estética minimalista y profesional diseñado para jóvenes. El proyecto combina contenido motivacional, consejos prácticos y experiencias de vida diaria con una interfaz visual limpia y funcional que funciona perfectamente en modo claro y oscuro.

## 🎨 Características Principales

### 🌟 Diseño Visual
- **Modo Claro/Oscuro**: Sistema completo de temas con cambio automático y manual
- **Diseño Profesional**: Colores limpios y modernos inspirados en GitHub
- **Alto Contraste**: Optimizado para máxima legibilidad en ambos modos
- **Transiciones Suaves**: Animaciones elegantes de 0.3s entre cambios
- **Tipografía Moderna**: Orbitron para títulos y Rajdhani para contenido

### 🧭 Menú Deslizante
- **Menú Vertical**: Botón hamburguesa que abre menú lateral deslizante
- **Overlay Completo**: Fondo oscuro que cierra el menú al hacer clic
- **Navegación Intuitiva**: Acceso directo a todas las secciones
- **Responsive**: Adaptado para desktop, tablet y móvil
- **Efectos Suaves**: Animaciones de apertura y cierre

### 📱 Páginas Principales
- **Inicio** (`index.html`) - Portal principal con resumen de posts destacados
- **Motivación** (`motivacion.html`) - Artículos inspiracionales y metas
- **Consejos** (`consejos.html`) - Tips y estrategias prácticas
- **Vida Diaria** (`vida-diaria.html`) - Rutinas y experiencias personales
- **Contacto** (`contacto.html`) - Formulario de contacto estilo terminal

### 📂 Sistema de Posts
- **Posts Individuales**: Artículos detallados en `/posts/`
- **Índice de Posts**: Página central con todos los posts organizados
- **Categorización**: Posts organizados por temática (motivación, consejos, vida diaria)
- **Navegación Integrada**: Acceso desde menú principal y entre posts

### 🎯 Formulario de Contacto
- **Terminal Interactiva**: Interfaz estilo consola con efectos visuales
- **Modo Local**: Funciona completamente sin backend
- **Feedback Visual**: Mensajes en tiempo real durante el envío
- **100% Funcional**: Simulación completa del proceso de envío

## 🛠️ Tecnologías Utilizadas

### Frontend
- **HTML5**: Estructura semántica moderna y accesible
- **CSS3**: 
  - Variables CSS para sistema de temas
  - Grid y Flexbox para layouts responsive
  - Animaciones y transiciones avanzadas
  - Media queries para diseño adaptativo
- **JavaScript Vanilla**: Interactividad pura sin frameworks

### Sistema de Temas
- **Variables CSS**: Sistema completo de colores para ambos modos
- **Detección Automática**: Adapta al preferencia del sistema
- **Toggle Manual**: Botón para cambiar entre temas
- **Transiciones Suaves**: Cambio gradual sin parpadeos

### Estilos y Efectos
- **Gradientes Modernos**: Efectos sutiles de profundidad
- **Box Shadows**: Múltiples capas para jerarquía visual
- **Keyframe Animations**: Efectos de entrada y hover
- **Backdrop Filters**: Efectos de cristal y profundidad

### Fuentes y Iconos
- **Google Fonts**: Orbitron (tecnológica) y Rajdhani (legible)
- **Iconos CSS**: Puro CSS para elementos gráficos
- **Emoji**: Iconos universales para mejor compatibilidad

## 🛠️ Instalación y Configuración

### Clonar el Proyecto
```bash
git clone [URL-del-repositorio]
cd BLOG
```

### Ejecutar Localmente
```bash
# Usar Live Server en VS Code
# O cualquier servidor HTTP local
python -m http.server 8000  # Python 3
# o
npx serve .  # Node.js
```

### Configuración para Despliegue
El proyecto está listo para despliegue sin configuración adicional:
- **Sin dependencias**: Funciona offline
- **Sin backend**: Todo el frontend es estático
- **Sin variables de entorno**: Configuración incluida
- **Multiplataforma**: Compatible con cualquier hosting

### Personalización
- **Colores**: Modificar variables CSS en `:root`
- **Fuentes**: Cambiar enlaces Google Fonts
- **Contenido**: Editar archivos HTML directamente
- **Temas**: Ajustar colores en `styles.css`

## 🎨 Guía de Estilos

### Sistema de Colores - Modo Oscuro
```css
--bg-primary: #0d1117;      /* Fondo principal */

--accent-primary: #58a6ff;  /* Azul principal */
--accent-success: #3fb950;  /* Verde */
--accent-danger: #f85149;   /* Rojo */
```

### Sistema de Colores - Modo Claro
```css

--light-text-primary: #0d1117; /* Texto principal */
--light-accent-primary: #0969da; /* Azul principal */
--light-accent-success: #1a7f37; /* Verde */
--light-accent-danger: #d1242f;  /* Rojo */
```
